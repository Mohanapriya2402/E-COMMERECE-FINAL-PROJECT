# 🛒 E-Commerce Sales Data Analysis Using Excel

## 📌 Project Overview

This project focuses on analyzing an E-commerce sales dataset using Microsoft Excel. The main objective is to transform raw data into a clean, structured, and analysis-ready dataset and develop an interactive dashboard to identify meaningful sales insights.

As an aspiring Data Analyst, I completed this project to strengthen my practical skills in data cleaning, Excel formulas, statistical analysis, Pivot Tables, and data visualization.

## 🎯 Objectives

- Import and organize raw E-commerce data using Excel Tables.
- Clean the dataset by handling missing values, duplicates, inconsistent data, and formatting errors.
- Remove irrelevant columns where necessary.
- Apply Excel formulas for calculations, logical operations, and text manipulation.
- Combine related tables using XLOOKUP/VLOOKUP, where applicable.
- Create Pivot Tables for data summarization.
- Calculate descriptive statistics to understand the data distribution.
- Build an interactive dashboard using charts and PivotCharts.
- Present key findings through a concise analytical report.

## 🔄 Project Workflow

### 1. Data Import & Organization

- Imported the dataset into Microsoft Excel.
- Organized the data into structured Excel Tables.
- Applied appropriate column headers and data formats.
- Checked data types and overall dataset structure.

### 2. Data Cleaning & Transformation

- Identified and removed duplicate records where appropriate.
- Checked for missing and blank values.
- Corrected inconsistent text entries and formatting errors.
- Standardized data formats.
- Validated values for accuracy and consistency.
- Removed irrelevant columns, if present.
- Documented the cleaning and transformation process.

### 3. Excel Formulas & Functions

Applied Excel functions to perform calculations and analyze the dataset.

| Function | Purpose |
|---|---|
| `SUM()` | Calculate total sales or other numeric totals |
| `AVERAGE()` | Calculate average values |
| `COUNT()` / `COUNTA()` | Count numeric or non-empty records |
| `COUNTIF()` | Count records matching a condition |
| `SUMIF()` | Calculate totals based on a condition |
| `IF()` | Apply logical conditions and categorize records |
| `MIN()` / `MAX()` | Identify minimum and maximum values |
| `LEFT()` / `RIGHT()` / `MID()` | Extract parts of text |
| `TEXT()` | Format dates and numeric values |
| `XLOOKUP()` / `VLOOKUP()` | Retrieve matching information from related tables |

*Note: Lookup functions are applied when compatible related tables and matching keys are available.*

### 4. Descriptive Statistical Analysis

Used Excel formulas and statistical tools to understand numerical data.

- Mean
- Median
- Mode
- Standard Deviation
- Minimum and Maximum
- Count and other relevant descriptive measures

These statistics help summarize the dataset and understand the distribution and variability of numerical values.

### 5. Pivot Table Analysis

Created Pivot Tables to summarize data across relevant dimensions, such as:

- Sales by category
- Sales by product or brand
- Sales by month, if date information is available
- Quantity and revenue comparisons
- Other relevant business performance measures

Applied sorting, filtering, and grouping wherever appropriate to identify useful patterns.

### 6. Data Visualization & Interactive Dashboard

Developed an Excel dashboard to present important metrics and trends visually.

**Visualizations included:**

- Bar Chart – Compare sales across categories or products.
- Column Chart – Compare performance across groups or periods.
- Pie Chart – Display category-wise contribution.
- PivotCharts – Visualize summarized Pivot Table results.
- Sparklines – Show compact trends within cells.

The dashboard is designed to make the results easier to understand and support data-driven decision-making. Interactive filters and slicers can be used where supported by the dashboard setup.

### 7. Reporting & Insights

Prepared a concise summary of the data preparation process, analytical approach, key findings, and business implications.

The report connects the results from Excel formulas, Pivot Tables, and charts to explain the main patterns identified in the dataset.
